# Client

Unity mobile game client for GulfRun.

**Status:** Sprint 12 — Gulf Maps & Level Design complete. Six beautiful, Gulf-inspired launch race maps (Kuwait City, Riyadh, Dubai, Doha, Manama, Muscat) sharing one fair, reusable 11-section-type level-structure library (Flat Sections/Small Hills/Slopes/Bridges/Wood Platforms/Stone Platforms/Jump Platforms/Short Tunnels/Open Areas/Small Drops/Small Climbs), every prefab keeping the same continuous, unbroken flat ground collider Sprint 3 established so platforms are always a bonus route, never a blocker; a data-driven `MapEnvironmentManager` that rolls a brand-new weighted Map + Weather (Sunny/Cloudy/Light Wind/Dusty Sky, plus Rain/Fog/Sandstorm authored at weight 0 for future support) + Time of Day (Morning/Sunset/Night, lighting-only) + fresh Trap/Item-Box random seeds at the start of every match, so trap/item-box placement can never be memorized into one perfect route; background-only per-city landmarks (Kuwait Towers, Kingdom Tower, Burj Khalifa, Doha Corniche/Pearl Qatar, Bahrain World Trade Center, Sultan Qaboos Grand Mosque, etc.) and a `BackgroundElementFlags` data flag per map (Clouds/Birds/Palm Trees/Waving Flags/City Lights At Night/Traffic/Sea Waves) driving a generic, reusable `ParallaxLayer` component; a dedicated ambient-audio channel on `AudioManager` for per-city Day/Night ambience; and a `MapDebugView` showing Current Map/Weather/Time/Trap Seed/Item Box Seed. No final landmark/background art, no final ambient audio clips, and no player-facing map-vote screen yet (see Sprint 12 Report §13).

**Prior status:** Sprint 11 — Daily Missions, Login Rewards & Reward System complete. 3 randomly-assigned Daily Missions (from a 25-entry configurable pool spanning Finish Races/Win Races/Collect Coins/Open Item Boxes/Use Weapons/Avoid Traps/Perform Jumps/Reach Top 3/Login Today) that reset every 24 hours across Easy/Medium/Hard difficulty with automatic reward scaling (1.0×/1.5×/2.0×); a 7-day Login Streak (Coins → Coins → Battle Pass XP → Gems → Temporary Cosmetic → Coins+Gems → weighted Mystery Reward) that resets to Day 1 on a missed day, plus 5 authored Special Login Event calendars (Ramadan, Eid, National Days, Summer, Winter); 2/3/7-day Temporary Cosmetics with live countdown timers, automatic removal (and auto-unequip) on expiry, and a Store "Unlock Permanently" upsell showing remaining time + Gem price; a "never grant a temporary duplicate — fallback to Coins/Gems instead" rule when a player already permanently owns a reward's cosmetic; Battle Pass XP as a first-class reward type; 4 new Mission/Login/Temporary-Item Notifications wired into Sprint 9's existing notification queue; and a mock-but-swappable cloud-ready `IProgressionBackendService` abstraction. No final reward-popup art/animation/SFX assets, no real backend, and no networked player avatar yet (see Sprint 11 Report §14).
